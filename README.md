# Elyria · Die fünf Tiefen – Updates

Dieses Repository verteilt die Spiel-Updates für den Elyria-Launcher. Der Launcher fragt beim Start
`stable/latest.json` ab und bietet neue Versionen zum Einspielen an (Prüfsumme + Rücksicherung).

## Aktuelle Version: 244.0.0

**Neu installieren:** [Elyria_Setup_V244.exe](https://raw.githubusercontent.com/schlumpf3110-byte/elyria-updates/main/stable/Elyria_Setup_V244.exe)

> Der Installer ist nicht digital signiert. Windows SmartScreen: „Weitere Informationen“ → „Trotzdem ausführen“.

## Verlauf

- **244.0.0** (2026-10-04): Lebensfunken, Abgrundwächter ab Gefahr 3, vier neue Waffenarten, Familienrunen, neue Werkbank-Vorteile, Lauf-Rückblick, Charakter des Tages, klarerer Kontrollpunkt
- **243.0.0** (2026-10-04): Kontrollpunkt nie mehr gesperrt, fünf neue Wächter, alle Wächter mit drei Phasen und starken Fähigkeiten
- **242.0.0** (2026-10-03): Fünf neue Charaktere mit eigenen Runen und Lieblingswaffen
- **241.0.0** (2026-10-03): Beutel in der Halle aufgeräumt: keine leeren Ausrüstungsfelder mehr, Hinweis auf Laufausrüstung
- **240.0.0** (2026-10-03): Kompakte Infoleiste im Dungeon, Details beim Halten von TAB
- **239.0.0** (2026-10-03): Fusion entfernt, schlichte Waffenleiste, kompakte Expeditionszentrale, Gefahrenstufen ersetzen die alte Schwierigkeit
- **238.0.0** (2026-10-03): Kartenpool aktualisiert, übersichtliche Runenschmiede mit Waffenvorschau, Kurzanleitung für neue Spieler
- **237.0.0** (2026-10-03): Waffenfamilien mit 2er/3er-Boni, Lieblingswaffen je Charakter (+20 % Schaden)
- **236.0.0** (2026-10-03): Gefahrenstufen 0-5 je Charakter: stärkere Gegner, höherer Laufertrag, Fortschritt auf den Charakterkarten
- **235.0.0** (2026-10-03): 10 Charaktere mit Stärken und Schwächen, 1 aus 5 Startwaffen, 16 Waffenarten, Ausrüstung pro Lauf, Laufertrag und Brens Werkbank
